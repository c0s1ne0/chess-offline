# ♟ 国际象棋 · 人机对战（离线版）

![对局预览](preview.png)

一个完全离线、无广告、单文件即可运行的国际象棋小游戏。适合已经懂规则、想轻松进阶又不想面对专业平台压力的玩家（多邻国式轻松向）。

## 特色功能

- **人机对战**：陪练 / 新手 / 简单 / 中等 / 困难 **五档难度**，可选执白（先手）或执黑（后手）
- **💡 提示**：卡住时点一下，高亮当前局面的最佳走法（起点 → 终点）并给出记谱
- **◀ 回看**：`上一步 / 下一步 / 回到当下`，随时翻看之前走过什么——**只回看，不改棋局**（和悔棋不同）
- **一句话教练**：走完一步即时点评；走得太差会提醒，送子会弹出「挂子预警」
- **小知识系统**：识别经典开局（意大利、西西里、西班牙、伦敦体系等 **16 个**），王车易位、吃过路兵、升变、将军、将杀、和棋等特殊时刻自动讲解
- **子力差距条**：实时显示双方子力差距
- **对局回顾**：评估曲线 + 每步标注（好棋 / 稍差 / 失误 / 败着）
- **复盘模式**：回放每一步、和最佳走法对比（可一键「摆出最佳走法」）
- **课后小课堂**：局末自动总结本局表现，按你暴露的问题推荐 1–3 个学习主题
- **棋谱导出**：SAN 棋谱 + 最终 FEN，方便复盘和分享
- **操作辅助**：悔棋、重新开始、棋盘缩放（会记住上次设置）、走棋提示开关
- **全中文记谱解释**：复盘时每步都有中文说明，附「棋谱符号怎么看」

## 界面与按钮

| 按钮 | 作用 |
| --- | --- |
| 💡 提示 | 高亮当前最佳走法（起点 → 终点 + 记谱） |
| ◀ 上一步 / 下一步 ▶ | 回看之前的走法，棋盘不会被误操作 |
| 回到当下 | 结束回看，回到真实局面继续下 |
| 悔棋 | 撤销你和 AI 的上一步（会改变棋局） |
| 重新开始 | 重开一局 |
| 导出棋谱 | 复制 SAN 棋谱 + FEN |
| 📊 查看复盘 | 对局结束后看评估曲线、逐步点评、最佳走法、课后小课堂 |
| － / ＋ | 缩放棋盘 |
| 走棋提示（勾选） | 开关「一句话教练」的即时点评 |

## 使用方式

1. **电脑**：直接打开 `国际象棋-人机对战-离线版.html`（推荐 Chrome / Edge）
2. **手机**：下载 `国际象棋-人机对战-离线版.zip` 解压，或用手机浏览器打开 HTML；建议「添加到主屏幕」当 App 用
3. 详细说明（含打包成 APK 的方法、常见问题）见 [使用说明.md](使用说明.md)

## 技术说明

- 纯 HTML + JavaScript 单文件实现，**无需联网、无需安装、无广告、无账号**
- 自研国际象棋引擎（合法走法生成、将军 / 将杀 / 逼和 / 升变 / 吃过路兵 / 王车易位，perft 1/2/3 = 20/400/8902 已验证）；AI 采用极小极大 + Alpha-Beta 剪枝
- **彻底离线**：文件内不含任何外部链接、字体或 CDN，飞行模式下也能正常对弈
- 数据本地存储（缩放设置等），棋谱可复制导出
